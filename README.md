# Коломийські тканини — інтернет-магазин

Node.js ≥ 22.13 + вбудований SQLite (`node:sqlite`). **Без зовнішніх npm-залежностей**: `npm install` не потрібен.

## Запуск
```bash
npm run create-admin -- you@example.com        # пароль (≥12 символів) вводиться прихованим вводом
npm run dev                                    # http://localhost:3000, адмінка: http://localhost:3000/admin
npm test                                       # 13 інтеграційних тестів
```
Міграції (`migrations/*.sql`) застосовуються автоматично при старті. Дані: `DATA_DIR` (за замовчуванням `./data`: `shop.db` + `uploads/`).
Тестові дані (лише dev): `npm run seed:demo` / `npm run unseed:demo` — товари позначені «ДЕМО», ціни умовні.

## Адміністратор
Перший обліковий запис створюється лише командою `create-admin` на сервері (паролів у коді немає). Ролі: `super` (все), `manager` (товари, категорії, замовлення), `editor` (сторінки). Приклад: `npm run create-admin -- ed@example.com editor`.

## Production
Змінні — у `.env.example`. Запуск: `NODE_ENV=production PUBLIC_URL=https://домен DATA_DIR=/var/lib/kolt npm start` за nginx із HTTPS (`TRUST_PROXY=1`); cookie стають `Secure`. Резервна копія: `npm run backup -- /шлях/shop.db` + копія `DATA_DIR/uploads`.

## Що реалізовано
Каталог (категорії, пошук, фільтри, сортування, пагінація), картка товару з варіантами, кошик (localStorage), замовлення (сума, залишки, ідемпотентність — на сервері), адмінка (огляд, товари + фото, категорії, замовлення + статуси/нотатки/історія, сторінки, налаштування, звернення), SEO (canonical, OG, sitemap, robots, JSON-LD без вигаданих рейтингів).

## Відомі обмеження
- Немає: мультимовності (рос. версія), новин/статей, FAQ, банерів, фото категорій, перегляду аудит-логу в інтерфейсі, онлайн-оплати (потрібен провайдер і ключі), сповіщень про нові замовлення.
- Кількість — цілі одиниці (метри); дробові метри не підтримуються.
- Rate limit — у пам'яті процесу; для кількох інстансів потрібен спільний сховок.
- Шрифти системні (CSP забороняє зовнішні); реальних фото немає — текстурна заглушка.
- Клієнтський JS (кошик, фільтри, мобільне меню) і візуальний дизайн не перевірялись у браузері.
